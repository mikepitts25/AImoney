2M.1 Spin Up Hetzner VPS & Install n8n

STOP — read before pasting a single command. n8n on plain HTTP is not enough even for testing: Vapi and Twilio webhooks refuse plain HTTP, so an HTTP install fails silently on Day 4-5 with no error to read. Install with HTTPS the first time. Day 2 is complete only when https://n8n.yourdomain.com loads with a padlock.

1Go to hetzner.com sign up. Create account. Verify email. Add a payment method (credit card or PayPal).

2Go to console.hetzner.cloud → create a new project. Name it "agency".

3Click "Add Server". Configure:

Location: pick the one closest to you (e.g., Ashburn for US East)

Image: Ubuntu 24.04 LTS

Type: Shared vCPU → CX22 (2 vCPU, 4 GB RAM) — $4.85/month

Networking: leave defaults (public IPv4 + IPv6)

SSH Key: click "Add SSH Key" if you have one. If you don't know what that is, skip it and use password authentication instead

Name: "n8n-server"

4Click "Create & Buy Now". Wait 30 seconds. Your server appears with an IP address. Write down the IP address (e.g., 168.119.xxx.xxx). Hetzner emails you the root password.

5SSH into your server. Open Terminal (Mac) or PowerShell (Windows):

ssh root@YOUR_IP_ADDRESS

Type "yes" when asked about fingerprint. Enter the root password from Hetzner's email.

6Point a subdomain at the server FIRST. In Namecheap → your agency domain → Advanced DNS → add an A record: Host n8n, Value = your server IP, TTL Automatic. HTTPS certificates cannot issue without this, and Vapi/Twilio webhooks refuse plain HTTP — there is no working plain-IP version of this setup.

7Install Docker + firewall.

apt update && apt upgrade -y curl -fsSL https://get.docker.com | sh ufw allow OpenSSH && ufw allow 80 && ufw allow 443 && ufw --force enable

8Create the stack (n8n behind Caddy with automatic HTTPS). Edit the two export lines, then paste the whole block:

# --- edit these two lines --- export N8N_HOST=n8n.yourdomain.com export N8N_EMAIL=you@yourdomain.com mkdir -p /opt/n8n && cd /opt/n8n cat > docker-compose.yml <<YAML services: caddy: image: caddy:2 restart: unless-stopped ports: ["80:80", "443:443"] volumes: - ./Caddyfile:/etc/caddy/Caddyfile - caddy_data:/data n8n: image: docker.n8n.io/n8nio/n8n restart: unless-stopped environment: - N8N_HOST=\${N8N_HOST} - WEBHOOK_URL=https://\${N8N_HOST}/ - N8N_PROTOCOL=https - GENERIC_TIMEZONE=America/New_York volumes: - n8n_data:/home/node/.n8n volumes: caddy_data: n8n_data: YAML cat > Caddyfile <<CADDY ${N8N_HOST} { tls ${N8N_EMAIL} reverse_proxy n8n:5678 } CADDY printf 'N8N_HOST=%s\nN8N_EMAIL=%s\n' "$N8N_HOST" "$N8N_EMAIL" > /opt/n8n/.env docker compose up -d sleep 20 && docker compose ps

Older guides set N8N_BASIC_AUTH_* variables — n8n removed those in 1.x. Your login is the owner account you create in the next step, not an env var.

9Verify. docker compose ps shows both containers running, and https://n8n.yourdomain.com loads the setup screen with a padlock. No padlock = DNS hasn’t propagated; wait 10 minutes, then docker compose restart caddy.

10Create the n8n owner account immediately — the setup screen is public until you do. Password from the shared vault; turn on 2FA under Settings.

11Write down your webhook base URL: https://n8n.yourdomain.com/webhook/ — every Vapi and Twilio URL in the rest of this course starts with it. Then click around: create a test workflow, drag a node, get comfortable. Tomorrow you build for real.

Day 3 — Learn n8n (Hands-On)

~5 hours

3.1 n8n Crash Course — Watch & Follow Along

1Go to YouTube → search "n8n getting started tutorial 2025" or "n8n beginner tutorial". Watch the official n8n channel's intro video (~20 min). Follow along in your own n8n instance — don't just watch passively.

2Key concepts to understand from this video:

Trigger nodes: These start a workflow (webhook, schedule, manual)

Action nodes: These do things (HTTP Request, send email, database query)

Connections: Drag from one node's output to another's input

Expressions: How to reference data from previous nodes (e.g., {{ $json.caller_name }})

Credentials: How to store API keys securely in n8n

3.2 Build Your First Practice Workflow

1In your n8n instance → click "New Workflow" → name it "Test - Webhook to Email".

2Add a Webhook node:

Click "+" → search "Webhook" → add it

Method: POST

Path: test-hook

Copy the "Test URL" shown (e.g., https://n8n.yourdomain.com/webhook-test/test-hook)

3Add a Set node (to transform data):

Click "+" after the Webhook → search "Edit Fields (Set)" → add it

Add a field: Name = "message", Value = New webhook received from {{ $json.body.name }}

4Add a Send Email node:

Click "+" after Set → search "Send Email" or "Resend" → add Resend node

Create credentials: paste your Resend API key

From: notifications@youragency.com

To: your personal email

Subject: Test notification

Body: {{ $json.message }}

5Test it: Click "Listen for Test Event" on the Webhook node. Then open a new browser tab and go to:

Open terminal and run: curl -X POST https://n8n.yourdomain.com/webhook-test/test-hook \ -H "Content-Type: application/json" \ -d '{"name": "Mike", "phone": "555-1234"}'

6Check: Did the workflow execute? Did you receive the email? If yes, you understand the basics of n8n. If not, check node error messages and fix.

7Save the workflow. Toggle it to "Active" (top right).

3.3 Practice: Webhook → Supabase

1Create a new workflow: "Test - Webhook to Supabase".

2Add Webhook node (same as before, path: test-supabase).

3Add Supabase node: Click "+" → search "Supabase" → "Insert Row".

Create credentials: Supabase URL + service_role key (from Day 2 step 2M.5)

Table: leads

Map fields: caller_name = {{ $json.body.name }}, caller_phone = {{ $json.body.phone }}, service_type = {{ $json.body.service }}

4Test with curl:

curl -X POST https://n8n.yourdomain.com/webhook-test/test-supabase \ -H "Content-Type: application/json" \ -d '{"name": "Jane Doe", "phone": "555-9876", "service": "AC Repair"}'

5Go to Supabase → Table Editor → leads table. You should see "Jane Doe" as a new row. If yes, you've connected n8n to your database.

Day 3 Done. You can now: trigger workflows via webhooks, transform data, send emails, and write to your database. These are the 4 building blocks of everything you'll build for clients. Tomorrow: Vapi.

Day 4 — Learn Vapi & Connect to n8n

~5 hours

4.1 Vapi Fundamentals

1Go to docs.vapi.ai/quickstart. Read the entire quickstart page (~15 min).

2Key concepts you need to understand:

Assistant: The AI voice agent itself — its personality, script, and behavior

Phone Number: Connects a Twilio number to an assistant

Tools/Functions: Actions the assistant can take (book appointment, transfer call)

Webhook (Server URL): Where Vapi sends data when events happen (call started, call ended, function called)

Transcriber: Converts speech to text (Deepgram is the default, works great)

Model: The LLM that powers the conversation (Claude, GPT-4, etc.)

Voice: The text-to-speech voice (ElevenLabs, PlayHT, etc.)

4.2 Create Your First Vapi Assistant

1In Vapi dashboard → "Assistants" → "Create Assistant".

2Choose "Blank" template. Name it: "Test HVAC Agent".

3Configure the Model section:

Provider: Anthropic (or OpenAI)

Model: claude-haiku-4-5-20251001 (fast + cheap for live calls) or gpt-5.4-mini. Verify current IDs before deploying — they change every few weeks.

Add your Anthropic API key in the credentials section

4Configure the System Prompt (this defines who the AI is). Paste this:

You are a friendly, professional scheduling assistant for Comfort Pro HVAC, a heating and air conditioning company. Your name is Alex. Your job: 1. Greet the caller warmly 2. Ask how you can help them today 3. Collect their information: full name, phone number, address, and what service they need 4. Determine urgency: Is this an emergency (no heat in winter, no AC in summer, gas smell, water leak) or can it wait? 5. If urgent: Tell them a technician will call back within 15 minutes 6. If not urgent: Offer to schedule an appointment 7. Confirm all details back to the caller 8. Thank them and end the call Services Comfort Pro offers: AC repair, AC installation, heating repair, furnace installation, maintenance tune-ups, duct cleaning, thermostat installation. Business hours: Monday-Friday 8 AM to 6 PM, Saturday 9 AM to 2 PM. Emergency service available 24/7. Service area: Metro area and surrounding 30-mile radius. Rules: - Be conversational and warm, not robotic - If they ask about pricing, say "Pricing depends on the specific situation. Our technician can give you an exact quote when they assess the job. We never charge hidden fees." - If they ask something you don't know, say "Let me take down your info and have our team get back to you with that answer right away." - You ARE an AI, and you say so. If the caller asks whether you are a person, a robot, or AI, answer immediately and plainly: "I'm an AI assistant for Comfort Pro — I can book you in right now, or have a technician call you back." Never dodge the question. - If asked whether the call is recorded, say: "Yes, calls are recorded so the team can follow up accurately." - Keep responses brief — 1-2 sentences max. This is a phone call, not a lecture.

5Configure Voice:

Provider: choose ElevenLabs or PlayHT

Voice: pick a natural-sounding voice. For HVAC, a friendly mid-range voice works well. Test several — click the play button to hear samples.

6Configure First Message (what the AI says when it picks up):

Thanks for calling Comfort Pro HVAC, this is Alex. How can I help you today?

7Click "Save".

8Test it using the Vapi web dialer. In the assistant view, there should be a "Test" or phone icon. Click it. Have a conversation with your own AI agent. Pretend to be a homeowner: "Yeah hi, my AC stopped working and it's 95 degrees in my house." See how it responds.

9Adjust the system prompt based on how the conversation went. Common fixes: "speak more briefly", "don't ask for info you already have", "confirm the appointment time more clearly". Re-test after each change.

4.3 Connect Twilio Phone Number to Vapi

1In Vapi dashboard → "Phone Numbers" → "Import from Twilio".

2Enter your Twilio Account SID and Auth Token (from Day 2).

3Your Twilio phone number should appear. Select it.

4Assign your "Test HVAC Agent" assistant to this phone number.

5Call the phone number from your cell phone. You should hear your AI agent answer with "Thanks for calling Comfort Pro HVAC, this is Alex..." Have a full test conversation.

If the call doesn't connect: Check Twilio console for error logs (Console → Monitor → Logs). Common issue: Twilio trial account not upgraded — you can only call verified numbers on trial. Upgrade to a paid account ($20 top-up) to call any number.

4.4 Set Up Vapi Webhook → n8n

1In n8n → create a new workflow: "Vapi Call Handler".

2Add a Webhook node: method POST, path: vapi-webhook. Copy the Production URL (not test URL). It looks like: https://n8n.yourdomain.com/webhook/vapi-webhook

3Activate the workflow (toggle to Active).

4In Vapi dashboard → your assistant → "Advanced" or "Server URL" → paste the n8n webhook URL.

5Call your Twilio number again. After the call ends, check n8n → go to your workflow → "Executions" tab. You should see data from Vapi including the call transcript, caller phone number, and any data the AI collected.

6Examine the data structure. Click on the webhook execution and look at the JSON. Write down the field paths for: caller phone number, call duration, transcript, and any collected data. You'll reference these when building the full workflow tomorrow.

Do not remove the AI self-ID line — it is a contract term, not a style choice. Your client agreement says “Provider configures the agent to disclose that it is an AI.” Utah gives you a safe harbour only if the agent says it is not human at the outset and when asked; Colorado’s Chatbot Safety Act adds penalties from Jan 2027. Every template you clone on Day 11 inherits this line, so a single deletion here propagates to every client. And it sells: “our agents always identify as AI — compliance handled” closes more contractors than pretending ever did.

Day 4 Done. You can now call a phone number and have an AI answer, conduct a conversation, and send the call data to n8n. This is the core product. Days 5-6 build it into a complete system.

2Test 5 different scenarios by calling the number:

Scenario 2: "I'd like to schedule a maintenance tune-up" (not urgent — should offer to book appointment)

Scenario 3: "How much does it cost to install a new furnace?" (pricing question — should handle gracefully)

Scenario 4: "Can I speak to a real person?" (transfer request — should handle with empathy)

Scenario 5: Incoherent / off-topic caller (should take a message and end politely)

3After each test, review the transcript in Vapi. Adjust the system prompt. Repeat until all 5 scenarios are handled well.

5.2 Add Function Calling (Structured Data Extraction)

1In Vapi → your assistant → "Tools" or "Functions" section.

2Add a new function called capture_lead. This tells the AI to extract structured data from the conversation and send it to your webhook.

3Define the function parameters:

{ "name": "capture_lead", "description": "Save the caller's information after collecting all required details", "parameters": { "type": "object", "properties": { "caller_name": { "type": "string", "description": "The caller's full name" }, "caller_phone": { "type": "string", "description": "The caller's phone number" }, "caller_address": { "type": "string", "description": "The caller's street address and city" }, "service_type": { "type": "string", "description": "The service they need (e.g., AC repair, heating, installation)" }, "urgency": { "type": "string", "enum": ["emergency", "normal"], "description": "Whether this is an urgent/emergency request" }, "notes": { "type": "string", "description": "Any additional notes about the request" } }, "required": ["caller_name", "caller_phone", "service_type", "urgency"] } }

4Set the function's server URL to your n8n webhook: https://n8n.yourdomain.com/webhook/vapi-webhook

5Update the system prompt to include: "After you have collected all required information (name, phone, address, service needed, and urgency), call the capture_lead function to save the information."

6Test: call the number, provide all your info. Check n8n executions — you should now see structured JSON with the caller's name, phone, service, etc. as clean fields, not buried in a transcript.

Day 6 — Build n8n Post-Call Workflows

~5 hours

6.1 Build the Main Call Handler Workflow

In n8n, open your "Vapi Call Handler" workflow. Build this flow step by step:

1Webhook node (already exists) — receives data from Vapi.

2Switch node — add after webhook. Route based on Vapi event type:

Condition 1: {{ $json.body.message.type }} equals "function-call" → route to lead capture flow

Condition 2: {{ $json.body.message.type }} equals "end-of-call-report" → route to call logging flow

3For the function-call branch (lead capture):

a. Add "Edit Fields" node — extract: caller_name, caller_phone, caller_address, service_type, urgency from the function call arguments

b. Add "Supabase" node — Insert row into "leads" table with the extracted fields. Set client_id = "demo" for now.

c. Add "Twilio" node — Send SMS to the caller:

Hi {{ $json.caller_name }}, thanks for calling Comfort Pro HVAC! We've received your request for {{ $json.service_type }}. A team member will contact you shortly. Reply STOP to opt out.

d. Add "Resend" node — Send email notification to the business owner:

Subject: New Lead: {{ $json.caller_name }} — {{ $json.service_type }} New lead captured by your AI phone agent: Name: {{ $json.caller_name }} Phone: {{ $json.caller_phone }} Address: {{ $json.caller_address }} Service: {{ $json.service_type }} Urgency: {{ $json.urgency }} Notes: {{ $json.notes }} {{ $json.urgency === 'emergency' ? '⚠️ URGENT — Call back within 15 minutes' : 'Normal priority — follow up within 24 hours' }}

4For the end-of-call-report branch (call logging):

a. Add "Supabase" node — Insert row into "call_logs" table: vapi_call_id, duration_seconds, transcript, recording_url

5Save the workflow. Make sure it's Active.

6Full test: Call the Twilio number. Go through an entire conversation. Provide name, phone, address, service. After hanging up, verify:

✓ Lead appears in Supabase "leads" table

✓ You received a confirmation SMS on your cell

✓ You received the email notification

✓ Call log appears in Supabase "call_logs" table

Twilio SMS setup: In n8n, add Twilio credentials (Account SID + Auth Token). The Twilio node needs: From number (your Twilio number), To number (the caller's number from the webhook data), and Body (the message text).

Day 8 — Build Follow-Up SMS Automation

~4 hours

1In n8n → new workflow: "Lead Follow-Up Sequence".

2Add a Schedule Trigger node → runs every 30 minutes.

3Add Supabase node → query leads table: SELECT * FROM leads WHERE status = 'new' AND follow_up_sent = false AND created_at < now() - interval '2 hours'

4Add a Loop Over Items node (to handle multiple leads).

5Inside the loop, add a Twilio Send SMS node:

Hi {{ $json.caller_name }}, just following up on your {{ $json.service_type }} request with Comfort Pro HVAC. Would you like to schedule a time for us to come out? Reply YES and we'll get you on the calendar.

6Add a Supabase Update node → set follow_up_sent = true for this lead.

7Save and activate. Test by manually inserting a test lead in Supabase with a created_at timestamp 3 hours ago. Wait for the schedule to trigger (or manually execute). Verify you receive the follow-up SMS.
